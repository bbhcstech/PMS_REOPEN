The bundled `iso-639-3.tab` contains the ISO 639-3 language code set published by
the SIL ISO 639-3 Registration Authority. Downloaded on 2026-10-09; 7,927 entries.

Source: https://iso639-3.sil.org/sites/iso639-3/files/downloads/iso-639-3.tab
Documentation and terms: https://iso639-3.sil.org/code_tables/download_tables

The source table is unmodified. The database import uses the ISO 639-1 code where
available and the ISO 639-3 code otherwise, preserving existing client selections.
The five legacy flag URLs are application presentation metadata, not part of ISO.
Languages without a flag display their language name alone.
